# 统计分析模块

## 概述

统计分析模块提供了强大的数据可视化和报表功能，帮助用户快速了解实验室运营状况。

## 功能模块

### 1. 统计仪表板 (StatisticsDashboard.vue)

统计仪表板是数据分析的核心页面，提供以下功能：

#### 主要功能
- **数据卡片展示**：显示关键指标（样品总数、待处理任务、合格率、异常样品）
- **趋势分析**：每个指标都显示环比增长趋势
- **多维度筛选**：支持按时间范围、样品类型、检测项目筛选
- **图表可视化**：
  - 样品数量趋势图（折线图）
  - 样品类型分布图（饼图）
  - 检测项目统计图（柱状图）
  - 合格率统计图（柱状图）

#### 导出功能
支持三种导出格式：
- **Excel**：导出统计数据为 Excel 表格
- **PDF**：导出整个仪表板为 PDF 文档
- **图片**：导出仪表板截图为 PNG 图片

#### 使用方法
1. 选择筛选条件（时间范围、样品类型、检测项目）
2. 点击"查询"按钮刷新数据
3. 点击"导出报表"下拉菜单选择导出格式
4. 系统自动生成并下载文件

### 2. 自定义报表配置 (CustomReportConfig.vue)

自定义报表配置允许用户根据需求创建个性化的统计报表。

#### 主要功能
- **报表管理**：创建、编辑、删除、查看自定义报表
- **指标选择**：从可用指标中选择需要统计的数据项
- **维度配置**：选择数据分析的维度（时间、样品类型、检测项目等）
- **筛选条件**：设置时间范围、样品类型、检测项目等筛选条件
- **图表类型**：支持折线图、柱状图、饼图、表格等多种展示方式
- **报表预览**：实时预览报表效果
- **报表导出**：支持导出为 Excel 或 PDF

#### 可选指标
- 样品数量
- 检测数量
- 合格数量
- 不合格数量
- 合格率
- 平均检测时长
- 任务完成率
- 异常样品数
- 复测次数
- 报告生成数

#### 可选维度
- 时间
- 样品类型
- 检测项目
- 检测人员
- 委托方
- 样品来源

#### 使用方法
1. 点击"新建报表"按钮
2. 填写报表基本信息（名称、描述）
3. 选择需要统计的指标
4. 选择分析维度
5. 设置筛选条件
6. 选择图表类型
7. 点击"预览"查看效果
8. 点击"保存"保存报表配置
9. 在报表列表中可以查看、编辑、导出已保存的报表

## 导出功能说明

### 导出工具 (exportUtils.ts)

系统提供了统一的导出工具类，位于 `src/utils/exportUtils.ts`。

#### 可用方法

1. **exportToExcel(data, filename)**
   - 导出数据为 Excel 格式
   - 参数：
     - `data`: 要导出的数据数组
     - `filename`: 文件名（不含扩展名）
   - 实际项目中建议使用 `xlsx` 或 `exceljs` 库

2. **exportToPDF(element, filename)**
   - 导出 HTML 元素为 PDF 文档
   - 参数：
     - `element`: 要导出的 HTML 元素
     - `filename`: 文件名（不含扩展名）
   - 实际项目中建议使用 `jspdf` 和 `html2canvas` 库

3. **exportToImage(element, filename)**
   - 导出 HTML 元素为图片
   - 参数：
     - `element`: 要导出的 HTML 元素
     - `filename`: 文件名（不含扩展名）
   - 实际项目中建议使用 `html2canvas` 库

4. **exportChartAsImage(chartInstance, filename)**
   - 导出 ECharts 图表为图片
   - 参数：
     - `chartInstance`: ECharts 实例
     - `filename`: 文件名（不含扩展名）
   - 使用 ECharts 内置的导出功能

5. **exportToCSV(data, filename)**
   - 导出数据为 CSV 格式
   - 参数：
     - `data`: 要导出的数据数组
     - `filename`: 文件名（不含扩展名）
   - 纯 JavaScript 实现，无需额外依赖

### 实际项目集成建议

当前导出功能为模拟实现，实际项目中建议安装以下依赖：

```bash
# Excel 导出
npm install xlsx

# PDF 导出
npm install jspdf html2canvas

# 或使用 pdfmake
npm install pdfmake
```

然后在 `exportUtils.ts` 中取消注释相应的实现代码。

## 技术栈

- **Vue 3**: 前端框架
- **TypeScript**: 类型安全
- **Element Plus**: UI 组件库
- **ECharts**: 图表库
- **导出库**（建议）:
  - xlsx: Excel 导出
  - jspdf: PDF 生成
  - html2canvas: HTML 转图片

## 注意事项

1. 当前导出功能为模拟实现，实际项目中需要集成真实的导出库
2. 图表数据为模拟数据，实际项目中需要对接后端 API
3. 导出大量数据时可能需要考虑性能优化
4. PDF 导出可能需要处理中文字体问题
5. 建议在服务端实现复杂的报表导出功能
