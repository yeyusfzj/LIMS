# 工作流管理模块

本模块包含工作流设计器和工作流模板管理两个主要功能。

## 1. 工作流设计器 (WorkflowDesigner.vue)

### 功能概述

工作流设计器是一个可视化的工作流编排工具，允许用户通过拖拽方式创建和配置实验室检测流程。

## 主要功能

### 1. 节点面板（左侧）
- **检测节点**：配置检测方法、派工规则和预期时长
- **审核节点**：配置审核级别、审核角色和审核要求
- **等待节点**：配置等待时长和超时处理
- **决策节点**：配置条件分支和决策逻辑

### 2. 画布区域（中间）
- 拖拽节点到画布创建工作流
- 拖动节点调整位置
- 自动绘制节点间的连接线
- 支持缩放和平移

### 3. 属性面板（右侧）
- 编辑选中节点的名称
- 配置节点特定属性
- 添加节点间的连接关系
- 设置通知规则

### 4. 工具栏
- **保存**：保存当前工作流配置
- **验证**：检查工作流的完整性和正确性
  - 检测孤立节点
  - 检测循环依赖
  - 验证必填配置
- **预览**：预览工作流执行效果
- **缩放控制**：放大、缩小、重置视图

## 使用方法

### 创建工作流

1. 从左侧节点面板拖拽节点类型到画布
2. 点击节点进行选择
3. 在右侧属性面板配置节点属性
4. 使用"连接到"下拉框添加节点间的连接
5. 点击工具栏的"保存"按钮保存工作流

### 编辑节点

1. 点击画布上的节点进行选择
2. 在右侧属性面板修改节点配置
3. 拖动节点调整位置
4. 点击节点上的删除按钮移除节点

### 验证工作流

点击工具栏的"验证"按钮，系统会检查：
- 工作流是否包含节点
- 是否存在孤立节点（未连接的节点）
- 是否存在循环依赖

## 节点类型说明

### 检测节点
用于配置样品检测任务，包括：
- 检测方法选择
- 自动派工设置
- 派工规则（按技能、工作负载、轮询）
- 预期完成时长

### 审核节点
用于配置审核流程，包括：
- 审核级别（分析审核、样品审核、技术审核、质量审核）
- 审核角色分配
- 是否必需审核
- 审核说明

### 等待节点
用于在流程中插入等待时间，包括：
- 等待时长设置
- 等待原因说明
- 超时处理方式（继续流程、发送通知、暂停流程）

### 决策节点
用于根据条件进行流程分支，包括：
- 决策条件表达式
- 条件类型（结果判断、状态判断、时间判断、自定义）
- 分支数量配置
- 各分支的条件设置

## 技术实现

- **框架**：Vue 3 Composition API
- **UI 组件**：Element Plus
- **图标**：@element-plus/icons-vue
- **样式**：SCSS
- **拖拽**：原生 HTML5 Drag and Drop API
- **图形绘制**：SVG

## 2. 工作流模板管理 (WorkflowTemplates.vue)

### 功能概述

工作流模板管理页面用于管理预定义的工作流模板，支持模板的创建、编辑、查看、配置和状态管理。模板可以关联到不同的样品类型，实现自动化的工作流应用。

### 主要功能

#### 1. 模板列表展示
- 显示所有工作流模板的列表
- 展示模板名称、版本、描述、适用样品类型、节点数量、状态等信息
- 支持按状态（草稿、启用、归档）筛选
- 支持按模板名称搜索
- 支持按适用样品类型筛选
- 分页显示，支持自定义每页显示数量

#### 2. 样品类型关联配置
- 为每个模板配置适用的样品类型
- 支持多选样品类型（水质、土壤、空气、食品、药品、化工、生物等）
- 配置自动应用规则：新建对应类型样品时自动使用该模板
- 实时保存配置更改

#### 3. 模板状态管理
- **草稿状态**：模板正在编辑中，未启用
- **启用状态**：模板可以应用于对应类型的样品
- **归档状态**：模板不再应用于新样品，但保留历史记录

#### 4. 模板操作
- **查看**：以只读模式查看工作流模板的详细配置
- **编辑**：修改工作流模板的节点和配置
- **配置类型**：设置模板适用的样品类型
- **启用**：将草稿状态的模板启用
- **归档**：将启用状态的模板归档
- **复制**：基于现有模板创建副本
- **删除**：删除不再需要的模板

### 使用场景

#### 场景 1：创建新模板
1. 点击"新建模板"按钮
2. 进入工作流设计器页面
3. 设计工作流节点和连接
4. 保存工作流
5. 返回模板列表，配置适用样品类型

#### 场景 2：配置样品类型关联
1. 在模板列表中找到目标模板
2. 点击"配置类型"按钮
3. 在弹出的对话框中选择适用的样品类型
4. 设置是否自动应用
5. 保存配置

#### 场景 3：启用模板
1. 找到状态为"草稿"的模板
2. 点击"更多"按钮，选择"启用"
3. 确认启用操作
4. 模板状态变更为"启用"，可以应用于对应类型的样品

#### 场景 4：复制模板
1. 找到要复制的模板
2. 点击"更多"按钮，选择"复制"
3. 输入新模板的名称
4. 系统创建模板副本
5. 可以对副本进行修改

### 样品类型说明

系统支持以下样品类型：
- **水质样品**：地表水、地下水、饮用水、废水等
- **土壤样品**：农田土壤、建设用地土壤、污染场地土壤等
- **空气样品**：环境空气、室内空气、废气等
- **食品样品**：农产品、加工食品、保健食品等
- **药品样品**：原料药、制剂、中药材等
- **化工样品**：化工原料、化工产品、危险化学品等
- **生物样品**：微生物、生物制品、生物材料等
- **其他样品**：不属于以上分类的样品

### 模板状态流转

```
草稿 (draft) → 启用 (active) → 归档 (archived)
     ↑              ↓
     └──────────────┘
         (编辑)
```

- 草稿状态的模板可以自由编辑
- 启用状态的模板可以应用于样品，编辑时需要确认
- 归档状态的模板不再应用于新样品，但保留历史数据

### 技术实现

- **框架**：Vue 3 Composition API
- **UI 组件**：Element Plus
- **路由**：Vue Router
- **状态管理**：响应式数据（ref, reactive）
- **样式**：SCSS

### 数据结构

```typescript
interface WorkflowTemplate {
  id: string                    // 模板ID
  name: string                  // 模板名称
  version: string               // 版本号
  description?: string          // 描述
  applicableTypes: string[]     // 适用样品类型
  nodes: WorkflowNode[]         // 工作流节点
  edges: WorkflowEdge[]         // 节点连接
  status: 'draft' | 'active' | 'archived'  // 状态
  createdBy: string             // 创建人
  createdAt: string             // 创建时间
  updatedAt: string             // 更新时间
}
```
