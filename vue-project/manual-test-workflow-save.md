# 工作流模板保存功能手动测试指南

## 测试目标
验证工作流设计器的保存功能已经修复，包括：
1. 显示保存对话框
2. 模板命名功能
3. 调用后端 API
4. 错误处理

## 测试步骤

### 1. 访问工作流设计器
- 打开浏览器访问：http://localhost:5173
- 登录系统（使用 admin/Admin@123456 或 testuser/User@123456）
- 导航到工作流设计器页面

### 2. 创建工作流
- 从左侧面板拖拽至少 2 个节点到画布
- 连接节点（选择节点后在右侧属性面板中选择目标节点）
- 确保工作流有效（可以点击"验证"按钮检查）

### 3. 测试保存功能
- 点击"保存"按钮
- **预期结果**：应该弹出保存对话框，包含：
  - 模板名称输入框（必填）
  - 模板描述输入框（可选）
  - 确定和取消按钮

### 4. 测试表单验证
- 不输入名称直接点击"确定"
- **预期结果**：应该显示验证错误提示
- 输入无效字符（如特殊符号）
- **预期结果**：应该显示格式错误提示

### 5. 测试成功保存
- 输入有效的模板名称（如："测试工作流模板"）
- 输入描述（可选）
- 点击"确定"
- **预期结果**：
  - 显示"保存中..."状态
  - 成功后显示成功提示
  - 询问是否查看模板列表

### 6. 测试错误处理
- 使用没有权限的用户登录
- 尝试保存模板
- **预期结果**：应该显示权限不足的错误提示

### 7. 测试取消功能
- 点击"保存"按钮
- 在对话框中点击"取消"
- **预期结果**：对话框关闭，表单数据被重置
