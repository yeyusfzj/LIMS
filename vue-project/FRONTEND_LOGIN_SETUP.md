# 前端登录功能设置指南

## 已完成的工作

✅ **登录页面** - 创建了完整的登录界面 (`/src/views/Login.vue`)
✅ **认证服务** - 实现了与后端API的认证通信 (`/src/services/auth.ts`)
✅ **状态管理** - 使用Pinia管理用户认证状态 (`/src/stores/auth.ts`)
✅ **路由守卫** - 添加了认证检查和自动跳转
✅ **HTTP拦截器** - 自动添加认证令牌和处理401错误
✅ **用户界面** - 在主布局中添加了用户信息和登出功能

## 如何测试登录功能

### 1. 启动后端服务

首先确保后端API服务正在运行：

```bash
cd backend-api
npm run dev
```

后端服务应该运行在 `http://localhost:3000`

### 2. 启动前端服务

```bash
cd vue-project
npm run dev
```

前端服务将运行在 `http://localhost:5173`

### 3. 测试登录

1. 访问 `http://localhost:5173`
2. 系统会自动跳转到登录页面 `/login`
3. 使用默认账号登录：
   - 用户名: `admin`
   - 密码: `Admin@123`

### 4. 验证功能

登录成功后应该能够：
- ✅ 自动跳转到首页 `/dashboard`
- ✅ 在右上角看到用户信息
- ✅ 点击用户头像可以看到下拉菜单
- ✅ 可以正常退出登录
- ✅ 退出后自动跳转回登录页

### 🎨 用户体验
- 响应式登录界面
- 加载状态提示
- 错误消息提示

## 故障排除

### 问题1: 登录时提示网络错误
**解决方案**: 检查后端服务是否正在运行，确认API地址配置正确

### 问题2: 登录成功但页面没有跳转
**解决方案**: 检查浏览器控制台是否有JavaScript错误

### 问题3: 退出登录后仍然可以访问页面
**解决方案**: 清除浏览器缓存和localStorage

### 问题4: 后端返回401错误
**解决方案**: 确认后端数据库中有默认用户数据，运行数据库种子文件

## API接口说明

前端已集成以下认证相关API：

- `POST /api/auth/login` - 用户登录
- `POST /api/auth/refresh` - 刷新令牌  
- `POST /api/auth/logout` - 用户登出
- `GET /api/auth/me` - 获取当前用户信息

所有API调用都会自动添加认证头，无需手动处理。
