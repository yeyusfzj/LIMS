## 📝 使用说明

### 1. 悬浮助手使用
- 点击右下角紫色按钮打开AI助手
- 输入问题或点击快捷操作
- 查看AI分析结果和建议
- 点击最小化或关闭按钮收起

### 2. AI洞察卡片
- 主页自动显示智能洞察
- 点击"刷新"更新分析数据
- 点击"与AI助手对话"打开悬浮助手
- 点击"查看详细分析"进入AI分析页面

### 3. 侧边菜单入口
- 统计分析模块下方
- "AI智能分析"菜单项
- 进入独立的AI分析页面

## 🔧 技术实现

### 组件架构
```
MainLayout (布局)
├── AIAssistantFloat (悬浮助手)
│   └── AIAssistant (对话界面)
│       ├── MessageItem (消息)
│       │   └── AnalysisResult (分析结果)
│       └── QuickActions (快捷操作)

Dashboard (主页)
└── AIInsightCard (洞察卡片)
```

### 数据流
```
Dashboard数据
    ↓
aiContextService.collectDashboardContext()
    ↓
生成上下文对象
    ↓
aiContextService.generateInsights()
    ↓
AI洞察数据
    ↓
展示在洞察卡片
```

### 样式系统
- **主题色**: `#667eea` → `#764ba2` (紫色渐变)
- **动画**: 滑入、脉冲、思考动画
- **响应式**: 桌面/移动端适配
- **深色模式**: 自动适配系统主题

## 🎨 设计亮点

1. **视觉区分** - 紫色渐变区别于系统蓝色主题
2. **流畅动画** - 所有交互都有平滑过渡
3. **智能提示** - 根据主页数据生成个性化建议
4. **多种展示** - 支持文本、指标、图表、表格
5. **响应式** - 完美适配各种屏幕尺寸
