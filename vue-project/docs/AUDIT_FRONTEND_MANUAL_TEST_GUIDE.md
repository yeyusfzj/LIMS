## 浏览器控制台检查

### 检查网络请求

在每个测试步骤中，打开浏览器开发者工具（F12），切换到"Network"标签，检查：

1. **审核任务列表请求**:
   - URL: `GET /api/audits?page=1&pageSize=20`
   - 状态码: 200
   - 响应包含 `items` 数组

2. **审核任务详情请求**:
   - URL: `GET /api/audits/{id}`
   - 状态码: 200
   - 响应包含 `task.instance.sample` 数据

3. **审核操作请求**:
   - URL: `POST /api/audits/{id}/review`
   - 状态码: 200
   - 请求体包含 `decision`, `comments`, `auditorId`

4. **提交审核请求**:
   - URL: `POST /api/audits`
   - 状态码: 201
   - 请求体包含 `taskId` (而不是 `sampleId`)

### 检查控制台错误

在"Console"标签中检查：
- [ ] 无 JavaScript 错误
- [ ] 无 API 调用失败
- [ ] 无类型错误或未定义变量
