# AI智能助手 - 快速开始指南

## 📖 概述

AI智能助手是实验室管理系统的核心功能之一,提供智能数据分析、趋势预测、异常检测和优化建议。

## 🚀 三种使用方式

### 1. 悬浮助手 (推荐)

**位置**: 页面右下角紫色渐变按钮

**使用步骤**:
1. 点击右下角悬浮按钮
2. 对话窗口自动展开
3. 输入问题或点击快捷操作
4. 查看AI分析结果
5. 点击最小化或关闭按钮收起

**特点**:
- ✅ 全局可用,任何页面都能访问
- ✅ 自动收集当前页面上下文
- ✅ 不影响当前工作流程
- ✅ 支持最小化,随时恢复

### 2. 主页洞察卡片

**位置**: 主页(Dashboard)欢迎区域下方

**功能**:
- 智能问候 - 根据时间和数据生成个性化问候
- 数据分析 - 展示关键指标的趋势和洞察
- 重要提醒 - 高亮显示需要关注的告警
- 智能建议 - 基于当前状态的优化建议

**操作**:
- 点击"刷新"按钮更新分析数据
- 点击"与AI助手对话"打开悬浮助手
- 点击"查看详细分析"进入AI分析页面
- 点击告警的操作链接快速跳转

### 3. 独立分析页面

**位置**: 侧边菜单 → AI智能分析

**路由**: `/ai/analysis`

**内容**:
- 左侧: AI洞察卡片(同主页)
- 右侧: 完整对话界面
- 底部: 功能特点说明

**适用场景**:
- 需要专注进行深度分析
- 需要查看完整对话历史
- 需要同时查看洞察和对话

## 💬 快捷操作

AI助手提供6种快捷操作,点击即可快速获取分析:

1. **📊 样品分析** - 分析当前样品状态和趋势
2. **⚠️ 异常检测** - 检测系统中的异常情况
3. **📈 趋势预测** - 预测未来数据趋势
4. **📄 报告生成** - 生成分析报告
5. **💡 方法推荐** - 推荐优化方法
6. **🎯 今日重点** - 查看今日工作重点

## 🎯 使用技巧

### 关键词触发

AI助手会根据关键词匹配不同的分析场景:

| 关键词 | 触发场景 | 示例问题 |
|--------|----------|----------|
| 样品、sample | 样品分析 | "分析一下样品情况" |
| 异常、anomaly、问题 | 异常检测 | "有什么异常需要关注?" |
| 趋势、预测、forecast | 趋势预测 | "预测下周的样品量" |
| 报告、report | 报告生成 | "生成本周分析报告" |
| 推荐、方法、recommend | 方法推荐 | "推荐优化方法" |
| 优化、资源、optimize | 资源优化 | "如何优化资源配置?" |
| 工作、重点、today | 今日重点 | "今天的工作重点是什么?" |
| 效率、提高、improve | 效率提升 | "如何提高检测效率?" |

### 最佳实践

1. **明确问题** - 问题越具体,AI回答越精准
   - ❌ "帮我分析"
   - ✅ "分析本周样品合格率趋势"

2. **使用快捷操作** - 常见需求直接点击快捷按钮
   - 比输入文字更快
   - 结果更标准化

3. **查看洞察卡片** - 先看AI主动提供的洞察
   - 可能已经回答了你的问题
   - 了解当前系统状态

4. **利用上下文** - AI会自动收集主页数据
   - 在主页打开助手,分析更准确
   - 提到"当前"、"现在"时会使用实时数据

## 📊 分析结果类型

AI助手可以返回多种类型的分析结果:

### 1. 文本回答
简单的文字说明和建议

### 2. 指标卡片
关键数据指标的展示:
- 指标名称
- 当前值
- 趋势(上升/下降)
- 同比/环比

### 3. 图表分析
可视化数据展示:
- 折线图(趋势)
- 柱状图(对比)
- 饼图(占比)
- 散点图(分布)

### 4. 表格数据
结构化数据展示:
- 样品列表
- 检测结果
- 统计汇总

### 5. 智能建议
可操作的优化建议:
- 问题描述
- 建议措施
- 预期效果

## 🎨 界面说明

### 消息类型

- **用户消息** - 蓝色气泡,右侧对齐
- **AI消息** - 紫色渐变气泡,左侧对齐
- **系统消息** - 灰色背景,居中显示

### 状态指示

- **AI思考中** - 三个跳动的点
- **在线状态** - 绿色圆点
- **消息时间** - 每条消息下方显示

### 交互反馈

- **发送按钮** - 输入内容后自动激活
- **清空对话** - 右上角垃圾桶图标
- **滚动加载** - 自动滚动到最新消息

## 🆘 常见问题

### Q: AI助手不显示?
A: 检查是否在MainLayout布局内的页面,404页面不显示悬浮助手。

### Q: 分析结果不准确?
A: 当前使用Mock数据,真实AI接入后会更准确。

### Q: 如何清空对话?
A: 点击对话窗口右上角的垃圾桶图标。

### Q: 可以导出对话记录吗?
A: 当前版本暂不支持,后续版本会添加。

### Q: 支持语音输入吗?
A: 当前版本暂不支持,已列入优化计划。
