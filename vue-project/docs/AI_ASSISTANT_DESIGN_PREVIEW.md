## 🎨 色彩方案

### 主题色
```css
/* AI助手专用渐变色 */
--ai-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 功能色 */
--ai-primary: #667eea;      /* 主色 - 紫色 */
--ai-secondary: #764ba2;    /* 辅助色 - 深紫 */
--ai-success: #48bb78;      /* 成功 - 绿色 */
--ai-warning: #ed8936;      /* 警告 - 橙色 */
--ai-danger: #f56565;       /* 危险 - 红色 */
--ai-info: #4299e1;         /* 信息 - 蓝色 */

/* 消息气泡 */
--ai-bubble-user: #667eea;      /* 用户消息背景 */
--ai-bubble-user-text: #ffffff; /* 用户消息文字 */
--ai-bubble-ai: #f7fafc;        /* AI消息背景 */
--ai-bubble-ai-text: #2d3748;   /* AI消息文字 */

/* 背景色 */
--ai-bg-primary: #ffffff;
--ai-bg-secondary: #f7fafc;
--ai-bg-hover: #edf2f7;
```

## ✨ 动画效果

### 1. 悬浮按钮脉冲动画
```
初始状态 → 放大 → 缩小 → 初始状态
   ●    →  ◉   →  ●   →    ●
(循环播放,2秒一次)
```

### 2. AI思考动画
```
● ○ ○  →  ○ ● ○  →  ○ ○ ●  →  ● ○ ○
(三个点依次跳动,0.6秒循环)
```

### 3. 消息滑入动画
```
新消息从下方滑入:
  ↓ (透明度 0 → 1)
  ↓ (位置 +20px → 0)
  ✓ (0.3秒完成)
```

### 4. 窗口展开/收起
```
展开: 从右下角放大 (scale 0 → 1, 0.3秒)
收起: 缩小到右下角 (scale 1 → 0, 0.3秒)
```

## 🎯 关键设计决策

### 1. 为什么选择悬浮按钮?
- ✅ 不占用页面空间
- ✅ 随时可访问
- ✅ 符合用户习惯(类似在线客服)
- ✅ 可以在任何页面使用

### 2. 为什么使用紫色主题?
- ✅ 区别于系统主色(蓝色)
- ✅ 紫色代表智能、科技、创新
- ✅ 与AI助手的定位相符
- ✅ 视觉上更有吸引力

### 3. 为什么提供快捷操作?
- ✅ 降低使用门槛
- ✅ 引导用户探索功能
- ✅ 提高交互效率
- ✅ 展示AI能力范围

### 4. 为什么先用Mock数据?
- ✅ 快速展示功能原型
- ✅ 前后端并行开发
- ✅ 便于演示和测试
- ✅ 预留真实AI接口
