# 工作流模板保存功能修复需求文档

## 简介

本文档描述了工作流设计器（WorkflowDesigner.vue）中保存模板功能的两个关键缺陷：
1. 保存模板时出现 403 Forbidden 错误
2. 缺少模板命名功能，导致无法为新建模板指定名称

这些缺陷导致用户无法正常保存和管理工作流模板，严重影响了工作流设计器的核心功能。

## Bug 分析

### 当前行为（缺陷）

1.1 当用户在工作流设计器中点击"保存"按钮时，系统发送 HTTP 请求到后端 API 并返回 403 Forbidden 错误

1.2 当用户在工作流设计器中点击"保存"按钮时，系统只是将工作流数据打印到控制台，没有提供任何界面让用户为模板命名

1.3 当用户创建新的工作流模板时，系统没有提示用户输入模板名称、描述等基本信息

1.4 当保存操作失败（403 错误）时，系统没有提供明确的错误提示或解决方案指引

### 期望行为（正确）

2.1 当用户在工作流设计器中点击"保存"按钮时，系统应该首先弹出对话框让用户输入模板名称和描述，然后成功保存到后端而不出现 403 错误

2.2 当用户在工作流设计器中点击"保存"按钮时，系统应该显示一个模态对话框，包含模板名称、描述等输入字段

2.3 当用户创建新的工作流模板时，系统应该在保存前验证模板名称不为空且符合命名规范

2.4 当保存操作成功时，系统应该显示成功提示并可选择返回模板列表或继续编辑

2.5 当保存操作失败时，系统应该显示具体的错误信息并保留用户输入的模板信息

### 不变行为（回归预防）

3.1 当用户在工作流设计器中拖拽节点、连接节点、配置节点属性时，系统应该继续正常工作

3.2 当用户在工作流设计器中点击"验证"按钮时，系统应该继续正常验证工作流的有效性

3.3 当用户在工作流设计器中点击"预览"按钮时，系统应该继续显示预览功能提示

3.4 当用户在工作流设计器中使用缩放、重置等画布操作时，系统应该继续正常工作

3.5 当用户删除节点或连接线时，系统应该继续正常更新工作流状态
