# 样品放行页面简化任务

## 概述

根据用户反馈，简化实现一个基础的样品放行页面。重点关注核心功能，避免复杂设计，使用现有组件和模拟数据。

## 简化任务列表

- [x] 1. 完善样品放行页面
  - 更新 `vue-project/src/views/sample/SampleRelease.vue` 页面
  - 使用 Element Plus 表格组件显示样品列表
  - 添加简单的搜索框（按样品编号或名称搜索）
  - 显示样品基本信息：编号、名称、客户、状态、放行条件

- [x] 2. 实现基本放行功能
  - 添加"放行"按钮（仅对状态为"已完成"的样品显示）
  - 实现简单的放行确认对话框
  - 显示放行成功/失败的消息提示
  - 放行后更新样品状态为"已放行"

- [x] 3. 使用模拟数据
  - 在现有的 `vue-project/src/mock/index.ts` 中添加样品放行相关的模拟数据
  - 模拟样品列表数据（包含不同状态的样品）
  - 模拟放行操作的API响应

- [x] 4. 简单的放行条件检查
  - 检查样品状态是否为"已完成"
  - 检查是否有检测结果（模拟数据）
  - 显示简单的放行条件状态（✓ 可放行 / ✗ 不可放行）

- [x] 5. 页面集成
  - 确保页面样式与现有系统保持一致
  - 验证页面在侧边菜单中的导航正常
  - 简单测试页面功能

## 简化原则

- **最小化功能**：只实现核心的样品列表显示和基本放行操作
- **复用现有组件**：使用系统中已有的 Element Plus 组件
- **模拟数据驱动**：不涉及真实的数据库操作，全部使用模拟数据
- **避免复杂逻辑**：不实现复杂的审核流程、电子签名等功能
- **保持独立性**：不修改其他页面或系统功能
