使用说明

  1. 启动开发服务器: npm run dev
  2. 访问交互式文档: http://localhost:3000/api-docs
  3. 下载 JSON 或 YAML 文件导入到 Postman
  4. 使用 OpenAPI Generator 生成客户端 SDK

API 分类

  • 认证: 用户认证和授权相关接口
  • 样品管理: 样品创建、查询、更新、流转、分样、合样等操作
  • 工作流: 工作流配置、实例管理、节点控制
  • 任务管理: 任务创建、分配、查询、完成
  • 检测结果: 结果录入、批量导入、公式计算、复测管理
  • 审核判定: 多级审核、质量判定、样品放行
  • 报告管理: 报告模板、报告生成、电子签名、分发回收
  • 统计分析: 数据统计、自定义报表、数据导出
  • 系统管理: 用户管理、角色权限、审计日志、数据备份
  • 权限管理: 权限配置、数据权限过滤
