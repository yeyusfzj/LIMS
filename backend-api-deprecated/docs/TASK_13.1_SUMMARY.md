## API 端点

### 创建模板
```
POST /api/report-templates
```

**请求体：**
```json
{
  "name": "检测报告模板",
  "description": "标准检测报告模板",
  "category": "检测报告",
  "content": "<html><body>样品名称: {{sampleName}}</body></html>",
  "variables": [
    {
      "name": "sampleName",
      "type": "string",
      "required": true,
      "description": "样品名称"
    }
  ]
}
```

### 查询模板列表
```
GET /api/report-templates?category=检测报告&isActive=true&page=1&pageSize=20
```

### 获取模板详情
```
GET /api/report-templates/:id
```

### 更新模板
```
PUT /api/report-templates/:id
```

### 激活模板
```
POST /api/report-templates/:id/activate
```

### 停用模板
```
POST /api/report-templates/:id/deactivate
```

### 删除模板
```
DELETE /api/report-templates/:id
```

### 获取版本信息
```
GET /api/report-templates/:id/versions
```

## 验证规则

### 模板创建验证
- `name`: 必填，1-200 字符
- `description`: 可选，最多 1000 字符
- `category`: 必填，1-100 字符
- `content`: 必填，不能为空
- `variables`: 必填，数组格式

### 变量定义验证
- `name`: 必填，必须符合变量命名规则（字母或下划线开头，只能包含字母、数字、下划线）
- `type`: 必填，必须是 string, number, date, boolean, array, object 之一
- `description`: 可选
- `required`: 可选，布尔值
- `defaultValue`: 可选
- `format`: 可选，用于日期格式化等

## 核心功能实现

### 1. 模板格式验证

模板使用 `{{variableName}}` 语法引用变量，支持嵌套属性访问：

```html
<html>
  <body>
    <h1>{{sample.name}}</h1>
    <p>检测结果: {{result.value}}</p>
  </body>
</html>
```

验证逻辑：
1. 提取模板中所有变量引用
2. 检查每个变量是否在变量定义中存在
3. 支持嵌套属性（如 `sample.name`，只需验证根变量 `sample` 存在）
4. 返回详细的验证错误信息

### 2. 版本控制

版本控制策略：
- 创建模板时版本号为 1
- 更新模板内容或变量时版本号递增
- 更新名称、描述等元数据时版本号不变
- 版本号单调递增，不可回退

### 3. 删除保护

删除模板前会检查：
- 是否有报告使用该模板
- 如果有关联报告，拒绝删除并提示先停用模板
- 只有未被使用的模板才能删除
