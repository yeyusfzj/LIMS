## 发现的问题及解决方案

### 问题1: Sample 和 WorkflowInstance 双向关联缺失
**发现阶段**: 后端 API 测试（任务 8.1）  
**现象**: API 返回的审核任务中，样品信息为 null  
**原因**: Sample 的 `workflowInstanceId` 字段未设置，导致无法通过 `task.instance.sample` 获取样品信息  
**解决方案**: 
- 创建修复脚本 `fix-sample-instance-relation.js`
- 为所有 Sample 设置正确的 `workflowInstanceId`
- 建立 Sample ↔ WorkflowInstance 的双向关联

**状态**: ✅ 已解决

---

### 问题2: 测试用户权限不足（403 Forbidden）
**发现阶段**: 集成测试（任务 8.3）  
**现象**: 执行审核操作时返回 403 权限不足  
**原因**: 
- 审核路由配置要求 `audit:approve` 权限
- 权限授予脚本只授予了 `audit:review` 权限
- 缺少 `audit:approve` 权限

**解决方案**:
- 更新 `grant-audit-permissions.js` 脚本
- 添加 `audit:approve` 权限
- 重新运行权限授予脚本

**状态**: ✅ 已解决

---

### 问题3: 审核人员ID验证失败（500 Internal Server Error）
**发现阶段**: 集成测试（任务 8.3）  
**现象**: 执行审核操作时返回 500 错误："您没有权限审核此任务"  
**原因**: 
- 审核服务验证 `auditTask.auditorId` 是否等于当前用户ID
- 集成测试脚本使用用户名（'test_auditor'）而不是用户ID
- 导致审核任务的 `auditorId` 与当前用户ID不匹配

**解决方案**:
- 更新集成测试脚本 `integration-test-audit-workflow.js`
- 在测试开始时获取测试用户的ID
- 使用用户ID而不是用户名创建审核任务

**状态**: ✅ 已解决

---
