## 附录

### A. 测试覆盖率详细数据

完整的覆盖率数据可在以下位置查看：
- HTML 报告: `htmlcov/index.html`
- JSON 报告: `coverage.json`
- 终端报告: 运行 `pytest --cov=app --cov-report=term-missing`

### B. 测试命令参考

```bash
# 运行所有测试
pytest

# 运行单元测试
pytest tests/unit/

# 运行集成测试
pytest tests/integration/

# 运行特定文件
pytest tests/unit/test_sample_service.py

# 运行特定测试
pytest tests/unit/test_sample_service.py::test_create_sample

# 生成覆盖率报告
pytest --cov=app --cov-report=html --cov-report=term-missing

# 显示详细输出
pytest -v

# 显示打印输出
pytest -s

# 并行运行测试（需要 pytest-xdist）
pytest -n auto
```
