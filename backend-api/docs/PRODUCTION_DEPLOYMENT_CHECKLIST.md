# 生产环境部署检查清单

本文档提供生产环境部署的完整检查清单,确保部署过程顺利且安全。

## 部署前检查 (Pre-Deployment)

### 环境准备

- [ ] **硬件资源检查**
  - [ ] CPU: ≥ 4 核心
  - [ ] 内存: ≥ 8GB RAM
  - [ ] 磁盘: ≥ 100GB 可用空间
  - [ ] 网络: 稳定连接,带宽 ≥ 100Mbps

- [ ] **软件依赖检查**
  - [ ] Docker 20.10+ 已安装并运行
  - [ ] Docker Compose 2.0+ 已安装
  - [ ] Git 已安装
  - [ ] curl/wget 已安装

- [ ] **网络配置检查**
  - [ ] 防火墙规则已配置
  - [ ] 端口 8000 (API) 可访问
  - [ ] 端口 5432 (PostgreSQL) 访问控制已配置
  - [ ] 端口 6379 (Redis) 访问控制已配置
  - [ ] SSL 证书已准备(如使用 HTTPS)
  - [ ] DNS 记录已配置

### 配置文件

- [ ] **环境配置**
  - [ ] `.env.production` 文件已创建
  - [ ] 数据库连接字符串已配置
  - [ ] JWT 密钥已配置(与 Node.js 后端相同)
  - [ ] Redis 连接已配置
  - [ ] CORS 域名已配置
  - [ ] 所有敏感信息已加密

- [ ] **Docker 配置**
  - [ ] `docker-compose.prod.yml` 已检查
  - [ ] 资源限制已配置
  - [ ] 健康检查已配置
  - [ ] 日志配置已设置
  - [ ] 卷挂载已配置

- [ ] **Nginx 配置** (如使用)
  - [ ] `nginx.conf` 已配置
  - [ ] SSL 证书路径正确
  - [ ] 上游服务器配置正确
  - [ ] 限流规则已配置
  - [ ] 安全头已添加

### 代码准备

- [ ] **代码质量**
  - [ ] 所有代码已通过 Code Review
  - [ ] 所有单元测试已通过
  - [ ] 所有集成测试已通过
  - [ ] 代码覆盖率 ≥ 80%
  - [ ] 静态代码分析已通过
  - [ ] 安全扫描已通过

- [ ] **版本管理**
  - [ ] 代码已合并到 main 分支
  - [ ] 发布标签已创建 (如 v1.0.0)
  - [ ] CHANGELOG 已更新
  - [ ] 版本号已更新

### 数据库准备

- [ ] **数据库检查**
  - [ ] 数据库连接测试通过
  - [ ] 数据库用户权限正确
  - [ ] 数据库备份已创建
  - [ ] 备份文件已验证
  - [ ] 迁移脚本已准备
  - [ ] 迁移脚本已在测试环境验证

- [ ] **数据库优化**
  - [ ] 索引已创建
  - [ ] 统计信息已更新
  - [ ] 慢查询已优化
  - [ ] 连接池配置已优化

### 监控和告警

- [ ] **监控配置**
  - [ ] Prometheus 已配置
  - [ ] Grafana 仪表板已准备
  - [ ] 告警规则已配置
  - [ ] Alertmanager 已配置
  - [ ] 日志聚合已配置 (Loki/ELK)

- [ ] **告警通知**
  - [ ] 邮件通知已配置
  - [ ] Slack/钉钉通知已配置 (可选)
  - [ ] 短信通知已配置 (可选)
  - [ ] 告警接收人已确认

### 文档准备

- [ ] **部署文档**
  - [ ] 部署指南已更新
  - [ ] 配置说明已完整
  - [ ] 故障排查指南已准备
  - [ ] 回滚流程已文档化

- [ ] **运维文档**
  - [ ] 监控指标说明已准备
  - [ ] 日志查看指南已准备
  - [ ] 常见问题解答已准备
  - [ ] 联系人信息已更新

### 团队准备

- [ ] **人员准备**
  - [ ] 部署负责人已确定
  - [ ] 运维团队已就位
  - [ ] 开发团队待命
  - [ ] 应急联系人已确认

- [ ] **沟通准备**
  - [ ] 部署时间已通知相关方
  - [ ] 维护窗口已公告
  - [ ] 沟通渠道已建立
  - [ ] 升级路径已明确

## 部署中检查 (During Deployment)

### 部署执行

- [ ] **部署前备份**
  - [ ] 数据库已备份
  - [ ] 备份文件已验证
  - [ ] 备份位置已记录
  - [ ] 当前版本已标记

- [ ] **代码部署**
  - [ ] 最新代码已拉取
  - [ ] Docker 镜像已构建
  - [ ] 镜像标签已正确
  - [ ] 旧镜像已备份

- [ ] **服务停止**
  - [ ] 旧服务已优雅停止
  - [ ] 所有连接已关闭
  - [ ] 容器已完全停止
  - [ ] 资源已释放

- [ ] **数据库迁移**
  - [ ] 迁移脚本已执行
  - [ ] 迁移日志已检查
  - [ ] 数据完整性已验证
  - [ ] 回滚脚本已准备

- [ ] **服务启动**
  - [ ] 新服务已启动
  - [ ] 容器状态正常
  - [ ] 日志无错误
  - [ ] 进程正常运行

### 健康检查

- [ ] **基础健康检查**
  - [ ] `/health` 端点响应正常
  - [ ] `/health/detailed` 显示所有服务正常
  - [ ] `/ready` 端点返回就绪
  - [ ] `/live` 端点返回存活

- [ ] **服务连接检查**
  - [ ] 数据库连接正常
  - [ ] Redis 连接正常
  - [ ] 外部 API 连接正常 (如有)
  - [ ] 文件系统访问正常

- [ ] **功能验证**
  - [ ] 登录功能正常
  - [ ] API 调用正常
  - [ ] 数据查询正常
  - [ ] 数据写入正常

## 部署后检查 (Post-Deployment)

### 功能验证

- [ ] **核心功能测试**
  - [ ] 用户认证功能正常
  - [ ] 权限控制功能正常
  - [ ] 样品管理功能正常
  - [ ] 工作流功能正常
  - [ ] 报告生成功能正常

- [ ] **API 测试**
  - [ ] 所有 API 端点可访问
  - [ ] API 响应格式正确
  - [ ] API 响应时间正常
  - [ ] API 错误处理正常

- [ ] **集成测试**
  - [ ] 前端集成正常

  - [ ] 数据库共享正常
  - [ ] 第三方服务集成正常

- [ ] **并发测试**
  - [ ] 支持 1000 QPS

  - [ ] 资源使用正常

- [ ] **资源使用**

### 常用命令

```bash
# 查看服务状态
docker-compose -f docker-compose.prod.yml ps

# 查看日志
docker-compose -f docker-compose.prod.yml logs -f fastapi-backend

# 健康检查
curl http://localhost:8000/health/detailed

# 重启服务
docker-compose -f docker-compose.prod.yml restart fastapi-backend

# 执行回滚
./scripts/rollback-production.sh

# 查看资源使用
docker stats fastapi-backend-prod
```

### 紧急联系流程

1. **发现问题** → 立即通知运维负责人
2. **评估影响** → 确定问题严重程度
3. **决策处理** → 修复或回滚
4. **执行操作** → 按流程执行
5. **验证结果** → 确认问题解决
6. **通知相关方** → 发送状态更新
7. **问题总结** → 编写事故报告
