# 生产环境部署前检查清单

在执行生产环境部署前，请逐项检查以下内容，确保所有准备工作已完成。

## 📋 检查清单

### 1. 系统环境检查

- [ ] **服务器资源充足**
  - CPU: ≥ 4 核心
  - 内存: ≥ 8GB
  - 磁盘: ≥ 100GB 可用空间
  - 网络: 稳定连接

- [ ] **必要软件已安装**
  - Docker 20.10+
  - Docker Compose 2.0+
  - Git 2.30+

- [ ] **依赖服务正常运行**
  - PostgreSQL 14+ 可访问
  - Redis 7+ 可访问（可选）

### 2. 配置文件检查

- [ ] **环境配置文件已创建**
  - `.env.production` 文件存在
  - 所有必需的环境变量已配置

- [ ] **数据库配置正确**
  - `DATABASE_URL` 指向正确的生产数据库
  - 数据库用户名和密码正确
  - 与 Node.js 后端使用相同的数据库

- [ ] **JWT 配置正确**
  - `JWT_SECRET_KEY` 使用强随机密钥
  - 与 Node.js 后端使用相同的密钥
  - 令牌过期时间配置合理

- [ ] **Redis 配置正确**
  - `REDIS_URL` 指向正确的 Redis 服务器
  - Redis 密码已配置
  - 连接池大小配置合理

- [ ] **CORS 配置正确**
  - `CORS_ORIGINS` 仅包含生产域名
  - 不包含 localhost 或测试域名

- [ ] **安全配置正确**
  - `DEBUG=false`
  - `ENABLE_SWAGGER_UI=false`
  - `ENABLE_REDOC=false`
  - `FORCE_HTTPS=true`
  - `RATE_LIMIT_ENABLED=true`
  - 密码策略配置为严格模式

- [ ] **邮件配置正确**（如果启用）
  - SMTP 服务器配置正确
  - 告警邮件接收人已配置

### 3. 代码和版本检查

- [ ] **代码已提交到版本控制**
  - 所有更改已提交
  - 没有未跟踪的文件
  - 工作目录干净

- [ ] **代码已通过测试**
  - 单元测试通过
  - 集成测试通过
  - 性能测试通过
  - 安全测试通过

- [ ] **代码已通过审查**
  - 代码审查已完成
  - 所有问题已解决
  - 已获得批准

- [ ] **版本标签已创建**
  - Git 标签已创建（如 v1.0.0）
  - 版本号已更新

### 4. 数据库检查

- [ ] **数据库备份已完成**
  - 最新的全量备份存在
  - 备份文件完整性已验证
  - 备份可以成功恢复

- [ ] **数据库迁移脚本已准备**
  - Alembic 迁移脚本已创建
  - 迁移脚本已在测试环境验证
  - 回滚脚本已准备

- [ ] **数据库性能已优化**
  - 索引已创建
  - 查询已优化
  - 连接池已配置

### 5. 网络和安全检查

- [ ] **域名和 DNS 已配置**
  - 域名 DNS 记录正确
  - SSL 证书已获取
  - SSL 证书有效期充足

- [ ] **防火墙规则已配置**
  - 允许 HTTP/HTTPS 流量
  - 限制数据库和 Redis 访问
  - SSH 访问已限制

- [ ] **负载均衡已配置**（如果使用）
  - 负载均衡器配置正确
  - 健康检查已配置
  - 会话保持已配置（如需要）

- [ ] **CDN 已配置**（如果使用）
  - CDN 配置正确
  - 缓存策略已配置
  - 源站保护已启用

### 6. 监控和告警检查

- [ ] **监控系统已配置**
  - Prometheus 已配置
  - Grafana 已配置
  - 监控指标正常收集

- [ ] **告警规则已配置**
  - 告警规则已创建
  - 告警阈值合理
  - 告警通知已配置

- [ ] **日志系统已配置**
  - 日志级别配置正确
  - 日志轮转已配置
  - 日志聚合已配置（如果使用）

### 7. 备份和恢复检查

- [ ] **备份策略已配置**
  - 自动备份已启用
  - 备份频率合理
  - 备份保留期已配置

- [ ] **恢复流程已测试**
  - 备份恢复已测试
  - 恢复时间可接受
  - 恢复流程已文档化

- [ ] **回滚方案已准备**
  - 回滚脚本已准备
  - 回滚流程已测试
  - 回滚决策标准已明确

### 8. 文档和沟通检查

- [ ] **部署文档已准备**
  - 部署步骤已文档化
  - 验证步骤已文档化
  - 故障排查指南已准备

- [ ] **团队已通知**
  - 部署时间已通知
  - 影响范围已说明
  - 联系方式已提供

- [ ] **用户已通知**（如需要）
  - 维护通知已发布
  - 预期停机时间已说明
  - 替代方案已提供

### 9. 部署窗口检查

- [ ] **部署时间已选择**
  - 选择低峰时段
  - 避开重要业务时间
  - 预留充足时间

- [ ] **团队成员已就位**
  - 部署人员已就位
  - 监控人员已就位
  - 支持人员已待命

- [ ] **回滚准备已就绪**
  - 回滚脚本已测试
  - 回滚决策人已明确
  - 回滚流程已演练

### 10. 最终检查

- [ ] **测试环境部署成功**
  - 在测试环境成功部署
  - 所有功能正常
  - 性能指标达标

- [ ] **部署计划已审批**
  - 部署计划已审查
  - 风险已评估
  - 已获得批准

- [ ] **应急预案已准备**
  - 应急联系人已明确
  - 应急流程已准备
  - 应急资源已就位
