```python
def query_equipment(self, experiment_type: str) -> List[Equipment]:
    """查询实验类型相关的设备"""
    exp = self._experiment_types.get(experiment_type)  # O(1) 查找
    if not exp:
        return []
    
    equipment_list = []
    for eq_id in exp.equipment_ids:
        eq = self._equipment.get(eq_id)  # O(1) 查找
        if eq:
            equipment_list.append(eq)
    
    return equipment_list
```

虽然当前性能已经足够，但如果未来数据规模大幅增长，可以考虑以下优化：

1. **查询结果缓存**: 缓存常用查询的结果
2. **LRU 缓存**: 使用 `functools.lru_cache` 装饰器
3. **数据库索引**: 如果切换到 SQLite，添加适当的索引
4. **分页加载**: 对于大量数据，实现分页查询
5. **异步查询**: 使用异步 I/O 提高并发性能

但在当前数据规模下，这些优化都是不必要的。
