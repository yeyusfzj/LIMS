# 大量测试数据生成说明

## 📋 概述

`seed_large_test_data.py` 脚本用于生成大量测试数据，以便测试系统的分页功能和性能。

## 🎯 生成的数据量

| 数据类型 | 数量 | 说明 |
|---------|------|------|
| 样品 | 150个 | 涵盖32种不同类型的样品 |
| 仪器 | 80台 | 涵盖28种不同类型的仪器 |
| 工作流模板 | 50个 | 每个模板包含5-10个步骤 |
| 工作流步骤 | 300-500个 | 根据模板自动生成 |
| 审核任务 | 120个 | 涵盖4个审核级别和多种状态 |

## 📊 数据特点

### 样品数据
- **样品类型**: 32种（水质、土壤、空气、食品、药品等）
- **客户公司**: 28家不同的检测公司
- **时间跨度**: 最近60天内的样品
- **状态分布**: registered, testing, completed, archived
- **优先级**: normal, high, urgent
- **位置**: 5个仓库区域，每个区域20个位置

### 仪器数据
- **仪器类型**: 28种（光谱仪、色谱仪、质谱仪等）
- **品牌**: 20个知名品牌（安捷伦、岛津、赛默飞等）
- **状态**: 正常、维护中、故障、停用、校准中
- **购置时间**: 1-10年前
- **校准周期**: 未来1-12个月内需要校准

### 工作流模板数据
- **模板类型**: 20种标准检测流程
- **版本管理**: 支持多版本（v1.0 - v5.9）
- **激活状态**: 75%激活，25%停用
- **步骤数量**: 每个模板5-10个步骤
- **分类**: 检测、审核、质控、管理

### 审核任务数据
- **审核级别**: 4个级别（分析审核、样品审核、技术审核、质量审核）
- **状态分布**: 
  - 待审核（PENDING）: 约30%
  - 已通过（APPROVED）: 约50%
  - 已拒绝（REJECTED）: 约10%
  - 已退回（RETURNED）: 约10%
- **时间跨度**: 最近30天内的任务

## 🚀 使用方法

### 1. 确保数据库已初始化

```bash
cd backend-api
python init_db.py
```

### 2. 运行大量数据生成脚本

```bash
python seed_large_test_data.py
```

### 3. 查看生成结果

脚本执行完成后会显示详细的统计信息：
- 各类数据的总数
- 数据分布情况
- 分页测试建议

## 📝 分页测试建议

### 前端分页配置

建议在前端列表页面使用以下分页配置：

```javascript
// 样品列表
{
  pageSize: 15,  // 每页15条
  pageSizes: [10, 15, 20, 50, 100]
}

// 仪器列表
{
  pageSize: 20,  // 每页20条
  pageSizes: [10, 20, 30, 50]
}

// 工作流模板列表
{
  pageSize: 10,  // 每页10条
  pageSizes: [10, 20, 30, 50]
}

// 审核任务列表
{
  pageSize: 15,  // 每页15条
  pageSizes: [10, 15, 20, 50]
}
```

### 后端分页参数

后端API应支持以下分页参数：

```python
@router.get("/samples")
async def get_samples(
    page: int = 1,           # 页码，从1开始
    page_size: int = 15,     # 每页数量
    sort_by: str = "created_at",  # 排序字段
    sort_order: str = "desc"      # 排序方向
):
    ...
```

## 🔄 重新生成数据

如果需要重新生成数据，脚本会自动清除现有的测试数据（保留用户数据），然后生成新的数据。

**注意**: 
- 脚本会删除所有样品、仪器、工作流模板和审核任务数据
- 用户数据不会被删除
- 建议在开发环境中使用，不要在生产环境运行

## 🛠️ 自定义数据量

如果需要生成更多或更少的数据，可以修改脚本中的数量参数：

```python
# 在 main() 函数中修改
samples = await create_samples(session, admin_user, count=150)      # 样品数量
instruments = await create_instruments(session, admin_user, count=80)  # 仪器数量
templates = await create_workflow_templates(session, admin_user, count=50)  # 模板数量
audit_tasks = await create_audit_tasks(session, samples, admin_user, count=120)  # 审核任务数量
```

## ⚠️ 注意事项

1. **数据库连接**: 确保数据库服务正在运行
2. **执行时间**: 生成大量数据可能需要1-2分钟
3. **内存占用**: 脚本会分批提交数据，避免内存占用过大
4. **数据清理**: 脚本会先清除现有测试数据，请确认后再运行
